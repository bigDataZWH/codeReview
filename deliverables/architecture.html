Code Review 架构可视化

六层架构 · 会话状态机 · 并发 Worker 池模型
1六层架构
Layer 1
Trigger · 触发层
HTTP API CLI Webhook SSE 流 接收审查请求, 支持多种触发方式
▼
Layer 2
Orchestrator · 编排层
DAG 编排 Agent 调度 重试降级 超时控制 Agent DAG 编排, 异常降级与 fallback
▼
Layer 3
Pipeline · 管道层
Diff 解析 文件过滤 Bundle 打包 规则匹配 AI 反思 确定性管道: 过滤→打包→规则→AI→后处理
▼
Layer 4
Agent · 代理层
Code Reviewer Impact Analyzer Security Reviewer Reflector Model Router 多 Agent 协作, 按复杂度路由 LLM 模型
▼
Layer 5
State · 状态层
会话存储 Findings 持久化 三级缓存 反馈闭环 自愈 状态机驱动, 支持断点续审与自愈
▼
Layer 6
Output · 输出层
CodeHub 评论 报表导出 Webhook 通知 告警 SSE 流 多渠道输出: 评论/报表/告警/通知
